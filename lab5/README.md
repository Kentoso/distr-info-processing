Лабораторна 5. Locally finite algorithms 
Необхідно реалізувати два алгоритми, в обох використовувати розпаралелюваня за допомогою потоків. Реалізації повинні гарантувати відсутність data race.

1. Задається граф та одна його вершина. Необхідно для усіх інших вершин знайти мінімальну відстань до заданої вершини. Алгоритм:

Starting: D[v0] = 0, ∀ w ≠ v0  D[w] = ∞,
c(v,w) = ∞ if (v,w) ∉ E,

DO for all v
{
    minimization of v that is:
        D[v] = min(D[v], D[w]+c(w,v) | (w,v) ∈ R^in(v))
}

Після N = |V| ітерацій гарантується що вектор D матиме мінімальні відстані від заданої вершини. Необхідно знайдені відстані вивести.

2. Задається граф, нехай кожна вершина має свій колір. Необхідно провести процедуру мінімізації розфарбування графа задля знаходження локально оптимального розфарбування (тобто коли мінімізація не змінює розфарбування для жодної вершини). При цьому зберігши властивість, що жодні дві суміжні вершини не можуть мати однаковий колір. Алгоритм: 
DO
CHOOSE randomly v; minimization(v);
END DO
minimization(v) передбачає присвоєння вершині найменшого кольору, але такого що немає у жодного сусіда.
Необхідно вивести отримане розфарбування та кількість виконаних ітерацій мінімізації.
