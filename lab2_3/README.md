Лабораторна 2. Пошук MIS у дереві
Реалізувати пошук найбільшої незалежної множини у дереві.
Вхідні дані: дерево (можна згенерувати або зчитувати з файла/захардкодити декілька варіантів дерев для тестування)
Вихідні дані: розмір MIS; індекси верших, що входять до MIS (якщо можливо декілька варівантів MIS, то обрати будь-який).


Лабораторна 3. Luby’s algorithm
Реалізувати Luby’s algorithm (пошук максимальної незалежної множини у довільному графі). Опис алгоритму можна знайти в методичці Nancy Lynch або в інтернеті.
Вхідні дані: довільний граф (можна згенерувати або зчитувати з файла/захардкодити декілька варіантів дерев для тестування)
Вихідні дані: розмір та індекси верших, що належать до максимальної незалежної множини (якщо можливо декілька варівантів MIS, то обрати будь-який).
